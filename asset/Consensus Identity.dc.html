  • Monochrome (all ink or all paper) is the default for anything under 20 px and on photos; the brass centre is for 20 px and up.
  • Clear space: two stroke intervals on every side. Never rotate, outline, or add a gradient.
  • The wordmark is always Instrument Serif Regular, never italic, never uppercase.
  • Never recolour side strokes by status. The mark is not a chart of any real asset.

Palette

Semantic meaning is fixed. Sage: within tolerance. Ochre: drifting. Vermilion: off-market, disputed, excluded. Brass is the agreed reference and the brand, never a status. Ochre fails AA as text on paper, so text uses ochre-ink #8A6417; the base ochre is for strokes and fills only. Same for brass-ink #86612A.
